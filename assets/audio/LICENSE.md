# Audio licensing

Every file in this folder was synthesized from scratch by `tools/make_audio.py`
(sine, square, triangle and noise generators, plus envelopes and filters). No
samples, loops, presets or third-party sounds were used.

The sounds and music are original work made for Evil Rage and are owned by the
project. They are safe to ship commercially, including on Steam. If you want to
regenerate or tweak them, edit the script and run `python3 tools/make_audio.py`.

If you later add third-party audio, list each file here with its source,
author and license (CC0 or a license that allows commercial use without
share-alike), so the store submission has a clear record.
